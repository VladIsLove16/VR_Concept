ДИАГНОСТИКА ЗАХВАТА — DIAG-2026-10-28

Назначение: выяснить, почему не снимается датчик при проверке на HTC XR Elite
через VIVE Hub + SteamVR. Причина ещё не установлена; это диагностическая сборка.
Unity и исходный проект для запуска не нужны.

КАК ПРОВЕРИТЬ
1. Полностью распакуйте архив. Не отделяйте EXE от папок и DLL.
2. Подключите шлем через VIVE Hub и SteamVR. Проверьте, что шлем и контроллеры
   видны в VR-среде и SteamVR назначен активным OpenXR runtime.
3. Запустите Start-Diagnostics.cmd из распакованной папки.
   Именно этот файл включает запись диагностики; обычный EXE её не включает.
4. Дойдите до снятия датчика и повторите проблему. Сделайте 2–3 отдельные попытки:
   поднесите свободную руку к датчику, нажмите Grip и отпустите кнопку.
   По возможности попробуйте другую свободную руку, ключ и запасной датчик.
5. Закройте приложение через Alt+F4. Откроется папка диагностических журналов.

ЧТО ПРИСЛАТЬ
- Самый свежий файл interaction-....log из открывшейся папки.
- Player-Diagnostics.log из распакованной папки рядом с EXE.
- Если заметили сообщение на панели при отказе — его текст или снимок экрана.

Папка журналов, если она не открылась:
%USERPROFILE%\AppData\LocalLow\DefaultCompany\VR_Concept\Diagnostics
Вставьте этот путь в адресную строку Проводника. Файлы каждой сессии отдельные.
Результаты сценариев по-прежнему сохраняются в соседней папке Attempts.

УПРАВЛЕНИЕ
Grip (кнопка захвата) — взять предмет рядом с рукой; отпускание — поставить.
Рабочая часть инструмента у крепежа + Trigger — действие инструментом.
Луч свободной руки + Trigger — кнопки; на свободном полу — телепортация.
Правый стик/тачпад вбок — поворот на 30 градусов.
На старте — «Знакомство»: включить линию и изучить три кнопки «i»;
затем перейти к замене датчика кнопкой на панели.
Для снятия датчика линия должна быть остановлена, кабель отключён,
обе гайки освобождены. Рука захвата должна быть свободна.

ЧТО ЗАПИСЫВАЕТСЯ
Доступные устройства и раскладки ввода, значения Grip, обнаружение предмета
рукой, начало/окончание захвата и причины отказа сценария. Состояние рук
также записывается раз в две секунды. Это помогает различить проблему ввода,
обнаружения предмета и условий обслуживания.
Сборка предназначена для диагностики взаимодействия; производительность
по ней не оценивается. Работа на физическом шлеме требует повторной проверки.
